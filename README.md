1. What is a website, and how is it different from a web application?



A website is a collection of pages that mainly show information, while a web application is interactive and lets users do tasks like logging in or submitting forms. In short, websites focus more on content, while web apps focus on user interaction.



2\. Why do you think organizations (like offices or schools) need websites?



Organizations need websites to share information, updates, and services with people easily. It helps them connect with students, staff, or the public in a fast and organized way.



3\. What challenges did you encounter while creating your first repository?



At first, it was confusing to understand how to set up files and use Git commands. Learning the process step by step made it easier over time.



4\. How might this practice of documentation (README) help in future projects?



README files explain the purpose and usage of a project, so anyone can understand it quickly. This makes teamwork and future updates easier and more organized.
